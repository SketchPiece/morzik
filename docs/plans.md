# Планы: новые входы для Морзика

Собрано 2026-10-23 по обзору Arc, Chrome и приложений на Маке. Что Морзик уже умеет, см. [notes.md](notes.md).

## В работе

- **Lotsia MCP.** Морзик ведёт поездки в Lotsia (перелёты, жильё, машина, брони) и рисует маршрут по письмам из почты. Проект `~/Documents/Projects/Lotsia`, отдельный тред в Штурвале.
- **Semafor MCP на Linux.** Telegram MCP из Semafor Mac станет доступен Морзику после переезда на сервер. Тред в проекте Semafor Mac.

## Разбор почты по типам

Письма уже приходят Морзику (подписка `mail`). Не хватает того, чтобы из них оставалось что-то, кроме сообщения в чате.

- Сервер по-прежнему шлёт все письма без сортировки. Тип определяет Морзик: поездка, заказ или доставка, счёт или подписка, запись или документ, остальное.
- Для каждого типа Морзик вынимает структурированную запись и кладёт её туда, где она живёт: поездки в Lotsia, счета и подписки в финансовый MCP, доставки в свой список. В чат пишет только то, что требует внимания.
- Разовый проход по почте за последние месяцы, чтобы заполнить всё задним числом.
- Скилл `mail-kinds` с описанием типов и куда что класть. Добавить тип = дописать раздел в скилле.

## Потом

- **Финансовый MCP.** Один сервер для денег: подписки и счета (из почты), выписки Wealthsimple (CSV/PDF), Wallet by BudgetBakers (REST API), при необходимости Stripe (ключ только на чтение). Календарь продлений, рост цен, неудачные списания, расходы по категориям. События по SEP-3415.
- **Покупки и доставки.** Amazon.ca, eBay: статус, задержки, сроки возврата. Из писем, через разбор почты по типам.
- **Apple Notes.** Имеет смысл после того, как заметки будут разобраны. Тогда локальный мост на чтение в духе `bridge/`.
